## 使用的 AI 工具

- Cursor（Agent 模式，Claude 模型）

## AI 辅助的范围

| 环节 | AI 产出 | 说明 |
|---|---|---|
| 方案 | 实现方案初稿及多轮自查修订 | 修订中发现并修正的问题包括：补查结果对规则检查不可见、参考实例替代时间排序不确定、幂等键包含文字导致重复草稿、保存缺少前置条件、用例间草稿污染、finish 可空字段的兼容性、PowerShell 输出编码等 |
| 代码 | `src/`、`scripts/`、`tests/` 全部初稿 | 原生 ReAct 循环、工具、校验、Mock、CLI |
| 数据 | `data/`、`examples/inputs/` | 合成数据，按方案中的数值生成 |
| 文档 | README 与 `docs/01-05` 初稿 | 个人部分见下方 TODO |

## AI 过程中的验证

- 所有 Mock 运行结果与方案中逐条写明的预期对照，一致后才写入 `03-evaluation.md`。
- 测试覆盖每个保存错误码、V1-V8 正反例，以及模型异常行为（`tests/test_agent_scripted.py`）。
- 写测试时发现一个 V8 用例设计错误：“不会发布成功之外的状态”中“发布成功”前一个字是“会”，正则会命中，与用例期望不符；已改为确实属于否定表述的用例，并在已知限制中说明 V8 的误判边界。
- 运行记录中的临时目录绝对路径会暴露本机用户名，已改为 `<tempdir>`。
- live 运行由 AI 在本机使用候选人提供的模型配置执行（密钥只存在于本地 `.env`，未进入对话或仓库）；AI 逐条阅读 10 份 live trace 后填写 `03-evaluation.md`，其中 live 08 与 Mock 结论不同，已如实记录。
